wechat-decrypt-derived optional Windows 4.x startup connector
=========================================================
Source: https://github.com/freanocank/wechat-decrypt
Revision: f0b3f9f95dda2d954ee3dbe1d139fb1944a5ecfd
Original source: scripts/windows/extract_raw_key.py
Copyright (c) 2026 cocofeng
License: MIT; see third_party/wechat-decrypt/LICENSE.

Adapted files: wechatbrain/capture_v4.js and wechatbrain/windows_capture.py.
Changes: startup capture is an explicit UI action; the user manually restarts
WeChat; no automatic termination, launch, signature change, or secret-file write;
same-user processes only; candidates require selected-database HMAC validation;
keys stay in RAM, while only public counters and status reach diagnostic output.
This adapter has not been verified on the user's WeChat 4.1.15.55 build.
The direct descriptor-capture path added in 0.6.1 is an independent implementation
based on documented static observations of the user-selected installed artifact.
It uses module-local instruction signatures and Frida IPC, not the vendor DLL,
global Windows hooks, receiver-window names, vendor cache files, or licensing code.
Both paths retain selected-database authentication and RAM-only candidate handling.

Tabler Icons, @tabler/icons 3.49.0, MIT License. Selected outline SVG icons from the official npm package; license: app/web/icons/LICENSE.txt in the portable distribution.

Adaptation: Python format checks, AES-ECB/XOR segment assembly and WXGF HEVC
