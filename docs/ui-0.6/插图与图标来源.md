共同提示：

> Use case: stylized-concept. Asset type: one isolated 3D onboarding illustration for a Chinese Windows chat-export utility, displayed at 110x110 CSS pixels. Soft glossy royal-blue and pale ice-blue plastic, clean rounded geometric objects, front view with a slight isometric angle, subtle soft ambient shadow, compact centered silhouette with 12 percent empty margin, actual transparent background. No text, no lettering, no brand, no watermark, no screenshot or surrounding UI. Consistent polished blue 3D icon family.

各图主题：

1. A blue smartphone standing upright with pale blue blank screen, tiny soft blue sphere accent.
2. A blue person account profile bust icon with round head and smooth shoulders, tiny blue sphere accent.
3. A blue file folder with a white upward export arrow on its front.
