把一个聊天文件夹丢进来，自动识别里面的数据（SQLite 库 / txt / JSON / HTML / CSV），
统一解析成结构化消息，导出 **JSONL + CSV + Markdown + HTML + Excel**。

- 纯本地运行，不联网、不写回原文件、不上传任何内容
- 零第三方依赖（xlsx 可选 openpyxl）；iOS 加密备份解密、SQLCipher 兜底解码都是纯 Python
- 专治三类真实场景：**Windows 微信目录**、**iPhone 备份/导出**、以及各家 IM 的导出文件

---

## 1. 快速开始

```bash
# 通用：任意聊天文件夹
python3 chatlog_extract.py --src "~/Downloads/聊天记录" --out chatlog_out

# Windows 微信：直接指到 WeChat Files / xwechat_files，或指到某个账号目录
python3 chatlog_extract.py --src "D:/WeChat Files" --out out
python3 chatlog_extract.py --src "D:/xwechat_files/wxid_xxx" --enc-key '数据库密钥' --out out

# iPhone：直接指到 Finder/iTunes 备份目录
python3 chatlog_extract.py --src "~/Library/Application Support/MobileSync/Backup/<UDID>" --out out
python3 chatlog_extract.py --src "~/.../Backup/<UDID>" --backup-password '备份密码' --out out

# 先体检：账号、库文件、是否加密，不解析
python3 chatlog_extract.py --src "D:/WeChat Files" --probe
python3 chatlog_extract.py --src "~/.../Backup/<UDID>" --probe --backup-password '备份密码'

# 多来源合并成一条时间线（--src 可重复，也可以一次给多个路径）
python3 chatlog_extract.py --src "D:/WeChat Files" --src "备份目录" \
        --backup-password '备份密码' --out out
```

跑完输出目录里是：

| 文件 | 说明 |
|---|---|
| `messages.jsonl` | 每行一条消息，字段最全，适合再加工 |
| `messages.csv` | 中文表头 + BOM，Excel 直接双击不乱码 |
| `messages.md` | 按会话分组的纯文本存档 |
| `messages.html` | 微信风格气泡报告，带搜索框和会话筛选 |
| `messages.xlsx` | 冻结首行 + 自动筛选的表格（需要 openpyxl） |
| `summary.json` | 来源识别、扫描/解析/去重统计、时间范围、错误与提示 |

## 2. 支持的来源

| 来源 | 长什么样 | 处理方式 |
|---|---|---|
| Windows 微信 3.x | `WeChat Files/<wxid>/Msg/Multi/MSG*.db` | 识别 `MSG` 表、`StrTalker` 会话、`IsSender` 方向 |
| Windows 微信 4.x | `xwechat_files/<wxid>/db_storage/message/message_*.db` | 识别 `Name2Id` + `Msg_<md5>`，还原发送者/会话 |
| Windows 联系人库 | `Msg/Contact/*.db`、`db_storage/contact/*.db` | 读 `Contact` / `ChatRoom` / `contact`，把 wxid 换成昵称备注 |
| iPhone 备份（未加密） | 目录里有 `Manifest.db` + `Info.plist` | 按 Manifest 映射取微信库，不碰其它 App |
| iPhone 备份（加密） | `Manifest.plist` 里 `IsEncrypted=true` | 用 `--backup-password` 解 keybag → 解 Manifest.db → 解库文件 |
| iOS 微信库文件夹 | `MM.sqlite` / `message_0.db` + `WCDB_Contact.sqlite` | 识别 `Chat_<md5>`、`Msg_<md5>` 表，群成员前缀拆发送者 |
| macOS 微信容器 | `~/Library/Containers/com.tencent.xinWeChat/...` | 按目录提示，加密库同样走 `--enc-key` |
| 通用导出 | QQ / 钉钉 / 飞书 txt、JSON、HTML、CSV | 原有通用解析，列名中英文别名都能对上 |

微信媒体消息（图片/语音/视频/表情/链接）正文为空时，会按类型补 `[图片]`、`[语音]`、
`[视频]`、`[表情]`、`[链接/文件]` 占位，保证时间线不断档；链接卡片的 XML 会被剥成
可读标题。需要原文加 `--keep-markup`。

## 3. 参数

| 参数 | 说明 |
|---|---|
| `--src PATH [PATH...]` | 聊天文件夹（可多个；`--src A B` 或重复 `--src` 都行） |
| `--out DIR` | 输出目录，默认 `chatlog_out` |
| `--probe` | 只体检来源：账号、库文件、大小、是否加密，然后退出 |
| `--platform auto\|win\|ios\|mac` | 平台提示，默认 auto 自动识别 |
| `--enc-key KEY` | SQLCipher 密钥：原始密码，或 `0x` 开头的 64 位十六进制 raw key |
| `--backup-password PWD` | iPhone 加密备份密码（只本地参与 keybag 推导，不落盘） |
| `--workdir DIR` / `--keep-work` | iOS 备份解包目录；默认系统临时目录并在跑完后清理 |
| `--since` / `--until` | 时间范围，`2024-01-01` 或 `2024-01-01 08:30` |
| `--keyword` | 内容关键词，可重复，任一命中 |
| `--conversation` / `--sender` | 按会话名 / 发送者过滤（包含匹配） |
| `--min-len N` | 正文最短长度，过滤空消息和撤回占位 |
| `--all-tables` / `--table NAME` | 不按评分过滤 / 只解析指定表 |
| `--keep-markup` | 保留 XML/HTML 原文（默认剥标签） |
| `--no-dedup` | 关闭跨文件去重（默认按 时间+发送者+内容） |
| `--formats` | `jsonl,csv,md,html,xlsx`，逗号分隔 |
| `--scan-only` / `--schemas` / `--quiet` | 只扫描 / 看表结构与命中评分 / 静默 |
| `--max-rows` / `--max-file-mb` | 单表读取上限（默认 50 万行）/ 单文件大小上限（默认 512MB） |

## 4. Windows 微信怎么跑

1. 路径：3.x 是 `文档\WeChat Files\<wxid>\`，4.x 是 `文档\xwechat_files\<wxid>\`。
   直接把 `WeChat Files`、`xwechat_files` 或某个 `wxid_xxx` 账号目录给 `--src` 都行。
2. 先 `--probe` 看库里有什么：会列出消息库、大小、加密与否、联系人库。
3. 库是加密的（文件头不是 `SQLite format 3`）时：

```bash
# 有密钥
python3 chatlog_extract.py --src "D:/WeChat Files" --enc-key '你的密钥' --out out
python3 chatlog_extract.py --src ... --enc-key 0x<64位十六进制> --out out

# 没有密钥：先用你惯用的工具导出明文库，再把导出目录给 --src
```

也可以把 64 位十六进制密钥存成 `key.txt` 放进账号目录（或 `WeChat Files` 目录），
工具会自动读取；直接把 64 位密钥贴给 `--enc-key` 也按 raw key 处理。

密钥的获取属于另一件事（各版本方式不同：内存扫描、调试器或第三方解密工具），
本工具只负责“有密钥之后把库解开并解析”。装了 `sqlcipher3-binary` 会优先用它；
没装时会用内置的纯 Python SQLCipher 解码（逐页 AES-256-CBC，试 4096/1024 页、
reserve 80/48、SHA512/SHA1、256000/64000 轮几组参数，用 `quick_check` 验收）。

## 5. iPhone 怎么跑

1. 先用 Finder（或 iTunes）做一次备份，位置：

```
~/Library/Application Support/MobileSync/Backup/<UDID>/
```

2. 把 `<UDID>` 目录给 `--src`；工具只从备份里取 `com.tencent.xinWeChat` 的库，
   不碰照片、通讯录、其它 App。加密备份要加 `--backup-password`：

```bash
python3 chatlog_extract.py --src "~/Library/Application Support/MobileSync/Backup/<UDID>" \
        --backup-password '你的备份密码' --out out
```

3. 解密链路（全在内存/临时目录里完成，跑完删除）：
   `PBKDF2-HMAC-SHA1(密码, Salt, Iterations)` → 解 keybag 里的保护类密钥 →
   RFC3394 解 `ManifestKey` → 解 `Manifest.db` → 每个文件再用自己的包装密钥解 →
   取出 `Documents/<hash>/DB/MM.sqlite`、`message_*.db`、`WCDB_Contact.sqlite`。
4. 备份里的微信用的是 SQLCipher 库：拿到库之后仍然可能需要 `--enc-key`（同上）。
   第三方工具（iMazing、爱思助手等）导出的 txt/csv/html 则直接给 `--src` 即可。

**边界**：只导出文字与占位符，不还原图片/语音/视频原文件；`-wal` 里未合并进主库的
最新几条可能缺失（可先用 SQLite 打开一次让它 checkpoint）。

## 6. 微信表结构适配

| 结构 | 关键列 | 处理 |
|---|---|---|
| `MSG`（Windows 3.x） | `StrTalker`、`StrContent`、`CreateTime`、`IsSender`、`Type` | 会话=StrTalker；自己发的标“我”；群聊 `wxid_xxx:\n` 前缀拆成发送者 |
| `Chat_<md5(wxid)>`（iOS MM.sqlite） | `CreateTime`、`Message`、`Des`、`Type` | `Des=1` 是自己；会话名用 `Friend` 表反查 md5 |
| `Msg_<md5(wxid)>` + `Name2Id`（4.x） | `create_time`、`message_content`、`real_sender_id`、`local_type` | `real_sender_id` 经 `Name2Id` 还原发送者；`local_type` 映射类型 |
| 联系人 | `Contact` / `ChatRoom` / `Friend` / `contact` 的 `userName|nickName|remark` | 昵称/备注优先，群名从 `ChatRoom` 取 |

## 7. 排查

| 现象 | 处理 |
|---|---|
| 一个文件都没发现 | 确认目录里有 `.db/.txt/.json/.html/.csv`；`--scan-only` 看发现列表 |
| 发现了库但 0 条 | `--schemas` 看评分，再试 `--all-tables` 或 `--table 表名` |
| 微信库提示加密 | 见第 4 节：`--enc-key`，或先导出明文库 |
| 密钥给了还是打不开 | 密钥不对，或库参数不在内置组合里；装 `sqlcipher3-binary` 再试 |
| iPhone 备份没解出库 | 备份里没装微信 / 微信没登录过；`--probe` 看“微信库文件”数量 |
| iPhone 备份解锁失败 | 密码错，或备份版本过老（老式 `Manifest.mbdb` 暂不支持） |
| 消息重复 | 默认已跨文件去重；确实想都留就加 `--no-dedup` |
| 时间显示不对 | 数据库存 UTC 秒，工具按本机时区转本地时间 |
