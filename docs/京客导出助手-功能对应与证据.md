在当前项目中重建虚拟机里轻虾导出助手的功能，命名为「京客导出助手」。继续提供逐联系人 AI 提炼重要信息、工作/生活/其他分类、带聊天依据的 Obsidian 笔记。

## REA 方法与覆盖

当前会话未连接 REA MCP。按 reverse-engineer-anything 技能使用固定版本 6.7.0 的 CLI，未修改 Codex 配置或安装原生分析引擎。

1. `doctor --client codex --json`：Codex 注册对齐；本机未配置 Hopper/Ghidra/IDA。
2. `inspect-go-binary`：成功读取 Go 构建信息，编译器记录为 go1.26.0，依赖包括 Wails、chromedp、SQLite、silk-go。
   Evidence：`ev_b77f82b51060c7d6e5c8f674570fbb032db80b72d3a2b76f2ed81b24f2f7ca3e`。
3. 用普通 Python 按 PE 文件映射与 Go embed.FS 描述符提取内嵌 HTML/JS/CSS，保存原文件偏移、字节长度和 SHA256。此步骤是普通字节解析，不能称为 REA 反编译。
4. 对完整前端运行 `analyze-javascript-application`。390,439 字节的脚本在 REA 默认 1024 MiB 工作堆中超限。已保留部分记录，不能称为完整语义恢复。
   Evidence：`ev_9bbcfdbf2606a3f04947b1b6f0ab46f5ed09c5a7e3b093ae9e365286da976696`。
5. 针对 exact bridge 声明提取 4,051 字节的独立输入，记录原脚本字符范围，再进行 REA 静态分析。此有限输入已解析，1,052 个 AST 节点，无解析失败。
   Evidence：`ev_fc2b7b5544daf6c0ac73c5c62d7e586a535d7ecbd05af37c31e1ce18c0711c9b`。

完整证据、提取脚本和第三方派生文件保存在本机 `.build-cache/qx-research/`，不进入发布包。发布包不含原程序、DLL、前端源代码、图标或授权实现。
