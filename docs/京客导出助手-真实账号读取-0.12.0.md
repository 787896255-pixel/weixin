## 读取连接的具体方式

REA 的 `main.loadKeys`、`main.keyStorePath` 与当前参考软件保存的文件格式共同确认：参考软件会在本机按账号保存 JSON 候选连接材料。

0.12.0 会在 Windows 上查找**所选账号对应的那一个文件**，对候选值进行数据库认证校验，通过后仅在本进程内存中复用。逐库仍要独立通过页认证、WAL 事务检查与 SQLite 副本检查。

本轮成功的是：**复用参考软件此前为当前账号保存的本地连接材料，再由本项目自己的代码解密、解析、存储与导出**。没有运行或打包参考软件的 EXE、DLL；没有修改其授权或会员判断。没有将连接材料写进报告、资料库或发布包。

本项目原有的进程读取与启动连接依然保留；**本轮没有证明完全没有已有连接材料时的首次独立连接已经成功**。这个范围需要单独完成实际验收。
