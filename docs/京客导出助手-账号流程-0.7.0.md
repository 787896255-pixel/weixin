## 本项目独立实现

| 功能 | 本次修改 | 边界 |
| --- | --- | --- |
| 首页账号选择 | 展示已导入账号缓存；选择后下一步 | “就绪”以实际导入消息为依据 |
| 添加微信 / 备份 | 自动发现常见目录、选择文件夹或填写路径 | 不扫描全盘，不把格式识别当作读取成功 |
| 账号详情 | 账号标识、会话与消息数量、记录目录、版本、导出目录 | 未恢复本人昵称时显示已有标识，不编造昵称 |
| 直接进入 | 从已导入缓存打开对应账号 | 即使源目录暂时不可达，仍能浏览缓存；这不表示保存了数据库密钥 |
| 打开电脑版微信 | 查找同用户进程、注册表和常见安装位置，启动实际客户端 | 只在 Windows 提供；进程存在不视为登录成功 |
| 重启并读取 | 明确确认后，结束当前用户同一可执行文件的微信，再启动、等待捕获并导入 | 仅用于微信 4.x 连接；不提升权限，不结束其他用户进程 |
| 手动重开连接 | 保留用户自行退出、重开并登录的路径 | 捕获最长 240 秒；支持取消与公共诊断 |
| 读取进度 | 检查目录、等待登录、连接、读取、确认 | 由实际后台状态驱动，失败不会假装完成 |
| 读取后确认 | 成功后显示账号、消息数；“查看记录”进入工作台 | 部分读取明确标示，仍能查看已导入部分 |
| 未合并 WAL | 提示退出微信，再用内存中的连接材料继续读取 | 未增加未经验证的加密 WAL 合并实现 |
| 账号切换 | 限定会话列表和“AI 提炼全部”的当前账号范围 | 清理跨账号勾选状态，避免误用上个账号的选择 |
| 导出目录 | 每账号记住目录，默认在 Documents/京客聊天导出下创建 | 禁止直接落到所选源目录内部；Obsidian 笔记仍使用设置中的库 |

微信扫码登录在已安装的官方电脑版微信窗口内完成。本项目没有展示假的二维码或短信登录成功，也没有接入轻虾的会员、服务账号和商业后台。受控捆绑微信分支尚未独立实现；当前使用本机已安装客户端。
